# Gradi Gestao

Sistema de gestao para lojas de roupas: vendas/PDV, produtos, clientes, fornecedores, condicional, crediario, financeiro, relatorios e etiquetas.

## Requisitos
- Node.js compativel com Vite

## Executar localmente
1. Instale as dependencias: `npm install`
2. Copie `.env.example` para `.env.local` e configure as variaveis necessarias, se aplicavel.
3. Inicie o ambiente de desenvolvimento: `npm run dev`

## Validacao
- `npm run lint`: verifica os tipos TypeScript.
- `npm run build`: gera a versao de producao.

Pastas temporarias do AI Studio, arquivos de backup embutidos e imagens nao referenciadas foram removidos. Os dados iniciais usados pelo sistema foram mantidos para evitar alterar o comportamento da aplicacao.
